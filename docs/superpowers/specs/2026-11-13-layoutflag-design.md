# LayoutFlag — Design

## Intent
Небольшая плашка поверх всех окон, показывающая флаг текущей раскладки
клавиатуры (RU/EN) активного окна. Перетаскивается мышью, позиция
запоминается. Замена малоинформативному значку в трее.

## Goals
- Всегда поверх всех окон (topmost), не крадёт фокус при клике.
- Флаг России для русской раскладки, флаг США для английской.
- Drag мышью за любое место плашки; позиция сохраняется между запусками.
- Закрытие — правой кнопкой по плашке (контекстное меню: Exit, а также
  «Автозапуск» — переключатель, кладущий/убирающий ярлык в shell:startup).
- Один exe, без внешних зависимостей.

## Non-goals
- Настройка цветов и размеров, GUI настроек, иконка в трее.
- Поддержка других языков кроме RU/EN (неизвестная раскладка → серая плашка).

## Constraints
- Windows 10/11, C# WinForms, .NET 8.
- Публикация: framework-dependent single-file (~150 КБ) + опция self-contained.
- Флаги — встроенные PNG-ресурсы (эмодзи-флаги Windows не рисует).
- Слежение за раскладкой: таймер 100 мс, GetForegroundWindow +
  GetKeyboardLayout(threadid) — дёшево и надёжно.

## Approaches
1. C# WinForms single-exe — выбрано: без рантайм-зависимостей при
   установлённом .NET, тривиальные topless/drag, лёгкая публикация.
2. AutoHotkey v2 — короче код, но требует AHK на каждой машине. Отклонено.
3. PowerShell + WPF — без установки, но неаккуратный автозапуск. Отклонено.

## Decisions
- Неактивная мышь: WS_EX_NOACTIVATE, чтобы клик по плашке не переключал окно.
- Позиция хранится в %APPDATA%\LayoutFlag\settings.json.
- Автозапуск — ярлык в shell:startup, переключается из контекстного меню.
