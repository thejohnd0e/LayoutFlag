# LayoutFlag — Настройки в трее (Design)

## Intent
Добавить в меню трея (и контекстное меню плашки) выбор режима отображения (флаги или одноцветные плашки), формы и размера плашки с мгновенным применением и сохранением.

## Decisions
- **Меню** (единое для трея и правого клика по плашке):
  - `Вид` → `Флаги` | `Цвет` (EN = `#2563EB`, RU = `#DC2626`, Unknown = `#6B7280`)
  - `Форма` → `Скруглённая` | `Прямоугольник` | `Круг`
  - `Размер` → `Маленький` (`36×24` / круг `28×28`), `Средний` (`56×38` / круг `40×40`), `Крупный` (`80×54` / круг `56×56`)
  - `Перезапустить`, `Автозапуск`, `Выход`
- **Отрисовка:** динамический GDI+ рендеринг (`BadgeRenderer`) + обрезка формы по `Form.Region` (`BadgeGeometry`) — честные углы без чёрной подложки вокруг круга/скругления, чёткость на всех размерах.
- **Хранение:** поля `Mode`, `Shape`, `BadgeSize` в `AppSettings` (`%APPDATA%\LayoutFlag\settings.json`), сохраняются сразу при выборе пункта меню и при закрытии.
